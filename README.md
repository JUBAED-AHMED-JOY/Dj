# 🎧 JOY DJ Remix

Make beats on your phone — no internet needed!

## Features
- 🥁 **8 drum pads** — Kick, Snare, HiHat, Open Hat, Clap, Tom, Cymbal, Bass (tap to play)
- 🎚️ **Beat sequencer** — 16 steps, BPM control (70–180), build your own beats
- ⏺️ **Recorder** — record your mix and save it to Downloads
